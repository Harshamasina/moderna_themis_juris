# Moderna Themis Juris Web Application

A modern single-page experience for Moderna Themis Juris OPC, highlighting legal research, compliance, and advisory capabilities across healthcare, pharmaceutical, food safety, and consumer protection sectors. The UI uses glassmorphism, responsive layout patterns, and SEO best practices to keep the experience crisp on every device.

## Tech Stack

- React 19 with Vite for lightning-fast development and builds
- React Router for routing, React Icons for expressive UI elements
- Custom glassmorphic UI system written in vanilla CSS

## Getting Started

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173/` by default. Edit components under `src/` and Vite will hot reload changes instantly.

## Production Build

```bash
npm run build
```

This outputs a fully optimized bundle in `/dist`, ready to deploy on any static host.
